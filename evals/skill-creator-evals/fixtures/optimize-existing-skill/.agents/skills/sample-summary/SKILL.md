# Sample Summary

Read the requested local Markdown note carefully before producing the summary.

The summary should be concise. Keep the summary short and avoid unnecessary detail. Do not make the
summary longer than it needs to be. Prefer a compact response rather than a verbose response.

Preserve the important facts from the note. Include the facts that matter and do not omit important
facts. Do not invent facts that are not present in the note. Base the summary only on the note.

Use plain language. Write clearly and directly. Avoid jargon when plain wording is available. Keep
the wording easy to understand.

Do not modify files. This is a read-only summarization task, so leave the repository unchanged.
